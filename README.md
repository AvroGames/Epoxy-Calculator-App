# Epoxy Coating Formulator

A simple browser-based calculator UI for building epoxy coating formulations.

## What it supports
- Enter epoxy components with equivalent weights and percentages
- Enter amine components with equivalent weights and percentages
- Add wetting aids, antifoams, fillers, and other additives as a percentage of the total formulation
- Calculate the resulting component masses for a target formulation weight

## Use it
Open [index.html](index.html) in a browser.

If you want, the next step can be to add:
- saved formulation templates
- export to PDF or CSV
- color-coded stoichiometric balance warnings
- a more detailed epoxy/amine database
